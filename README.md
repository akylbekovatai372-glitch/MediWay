# MediWay — MVP demo

Демонстрационная медицинская навигационная платформа для Бишкека на Next.js App Router, TypeScript, Tailwind CSS и Leaflet/OpenStreetMap.

> Все учреждения, имена, адреса, контакты, цены и координаты в проекте вымышлены и служат только для демонстрации. Статус записей — «Не проверено». Каталог не содержит подтверждённых данных о наличии лекарств.

## Запуск

Требуется Node.js 20+.

```bash
npm install
npm run dev
```

Откройте http://localhost:3000. Для производственной сборки: `npm run build`, затем `npm start`.

## Страницы

- `/` — главная и поиск.
- `/catalog` — поиск, фильтры по категории и району, сортировка.
- `/organizations/[id]` — профиль учреждения.
- `/doctors` — поиск по демонстрационным профилям врачей.
- `/map` — интерактивная карта OpenStreetMap с фильтрами категорий.
- `/navigator` — сценарный информационный навигатор без подключения AI.
- `/login`, `/register`, `/profile` — интерфейсы демо-кабинета без регистрации и хранения данных.
- `/admin` — демонстрационная панель без серверной авторизации.

## Данные и будущая интеграция

Демонстрационные записи находятся в `data/facilities.ts`, типы — в `types/index.ts`. UI использует эти типы и может позднее получить источник данных через отдельный слой `lib/` и серверные функции. Supabase и база данных сейчас не подключены.

Карта использует тайлы OpenStreetMap; атрибуция отображается в карте. Для production-размещения нужно учитывать политику использования тайлов OSM. Каталог и навигатор работают независимо от карты.

## Деплой

Проект готов для импорта в Vercel из GitHub. Framework preset: Next.js, build command: `npm run build`. Секреты и платные API не требуются. Для настройки собственного домена/среды подключите репозиторий в аккаунте Vercel.

## Ограничения демо

- Нет реальных медицинских организаций, подтверждённых врачей или актуальных цен.
- Формы входа и регистрации ничего не отправляют и не сохраняют.
- Навигатор работает на заранее подготовленных сценариях, не является медицинской консультацией и не принимает фотографии.
- Админ-панель не имеет серверной авторизации и не сохраняет правки.
- Структура UI не хранит введённые навигатором сведения о здоровье.
